# 색상 기반 객체 인식

## 구현 내용

한 장의 이미지에서 빨강, 파랑, 초록 객체를 동시에 인식하고 각 객체에 서로 다른 색상의 Bounding Box를 표시하였다.

## 사용한 기법

입력 이미지를 BGR에서 HSV 색 공간으로 변환한 뒤 `cv::inRange()`를 이용하여 빨강, 파랑, 초록 영역을 각각 이진 마스크로 분리하였다.

빨간색은 Hue 값이 HSV 범위의 시작과 끝에 나누어져 있기 때문에 두 개의 마스크를 생성하고 `cv::bitwise_or()`로 합쳤다.

색상 마스크의 작은 노이즈를 제거하기 위해 Opening 연산을 사용하고, 객체 내부의 작은 구멍이나 틈을 보완하기 위해 Closing 연산을 사용하였다.

이후 `cv::findContours()`로 객체의 윤곽선을 검출하고, `cv::boundingRect()`를 이용해 각 객체의 경계 사각형을 구하였다.

마지막으로 `cv::rectangle()`을 이용하여 빨간 객체는 빨간색, 파란 객체는 파란색, 초록 객체는 초록색 Bounding Box로 표시하였다.

## 선택 이유

HSV 색 공간은 색상, 채도, 밝기를 분리해서 표현할 수 있어 BGR보다 특정 색상의 객체를 구분하기 편리하다고 판단하였다.

Opening과 Closing 연산은 색상 마스크의 노이즈와 작은 빈 영역을 정리하여 보다 안정적인 윤곽선 검출을 하기 위해 사용하였다.

## 결과

빨강, 파랑, 초록 객체를 동시에 인식하였으며, 각 객체에 해당 색상의 Bounding Box를 표시하였다.

최종 결과 이미지는 `result.png`로 저장하였다.
